## set裡的multiset
multiset是一個可以自動排序的籃子，但是有些地方需要注意
- `.end()`會指向最後一項的後面，所以在刪除==時需要加上`prev()`往前一格
- 刪除最小及最大值時，需要注意erase裡的函式是`迭代器`還是`數值`，如果是迭代器，因為是指標，所以只會刪除指標所向的地方<Br>
但是如果寫erase(100)，則會把multiset裡面值為100的**全部**刪掉，需多加注意
- `res+=*prev(money.end())-*money.begin();`，因為end()和begin()屬於迭帶器，所以在提領時須加上`*`
